# U too

香川のお店を、営業時間・場所・気分から探せる個人制作アプリです。HTMLファイル1つで動き、インストールは要りません。

| アプリ | 内容 | ファイル |
|---|---|---|
| 🍜 U too | 香川のうどん店（108店） | [utoo.html](utoo.html) |
| 🍰 U too Sweets | 香川のスイーツのお店（100店） | [utoo-sweets.html](utoo-sweets.html) |
| ⚡ Ikki too（番外編） | 日本で買える栄養ドリンク（52種） | [ikki-too.html](ikki-too.html) |

## 使い方

スマホのブラウザで開くだけです。

- トップページ：`https://<ユーザー名>.github.io/utoo/`
- うどん：`https://<ユーザー名>.github.io/utoo/utoo.html`
- スイーツ：`https://<ユーザー名>.github.io/utoo/utoo-sweets.html`
- 栄養ドリンク：`https://<ユーザー名>.github.io/utoo/ikki-too.html`

ホーム画面に追加すると、アプリのように使えます。

## できること

- いま営業しているお店をさがす（曜日・時刻の指定もできます）
- エリア・ジャンル・気分・食べ方でしぼりこむ
- 店名や名物（「釜バター」「瓦せんべい」など）で検索する
- 何店か回る旅プラン、シェアサイクルで回るチャリ旅プランを作る
- 地図で場所を見る

## お店の情報について

- 営業時間・定休日は、各店の公式サイト、観光協会、地元メディア、グルメサイトなどの公開情報を照らし合わせて登録しています。
- 情報源によって内容が違う場合は、公式サイトの情報を優先しています。公式サイトがない場合は、営業時間が短いほう・休みが多いほうを表示し、違いを各店の注意書きに書いています。
- わからない営業時間を推測で埋めることはしていません。
- 地図のピンは、Google マップに掲載されている店舗の位置と照らし合わせています。

**営業時間や定休日は変わることがあります。お出かけ前に、各店の最新情報をご確認ください。**

## 栄養ドリンク（Ikki too）について

- 価格は2026年10月時点で通販・店頭の公開価格を調べた参考価格（税込）です。確認できなかったものは「要確認」と表示し、推測で埋めていません。
- 強さのレベルは、区分・生薬の数・価格からこのアプリが付けた目安で、効き目を保証するものではありません。
- 用法・用量を守ってください。持病がある方・服薬中・妊娠中の方は、薬剤師か登録販売者に相談してください。
- 商品の写真は載せていません。画面のボトルはイラストです（写真は各自の端末で差し替えできます）。

## プライバシー

お気に入りなどの情報は、お使いのブラウザの中だけに保存されます。サーバーには何も送信しません。
